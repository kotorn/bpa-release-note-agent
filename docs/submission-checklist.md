# Submission Checklist

Use this checklist immediately before submission.

## Repo

- [ ] `pwsh ./scripts/verify.ps1` exits `0`
- [ ] Privacy scan passes
- [ ] Gitleaks passes on working tree and history
- [ ] `ACCEPTANCE.md` has no unchecked items
- [ ] `CODEX-FINAL-REPORT.md` is present and current

## Public Content

- [ ] Public samples use synthetic data only
- [ ] No real tenant IDs are committed
- [ ] No real UPNs or email addresses are committed
- [ ] No internal URLs are committed
- [ ] No secrets are committed
- [ ] No production screenshots are committed

## Human Gates

- [ ] Tenant login is complete
- [ ] Copilot Studio UI work is complete
- [ ] Power Automate UI work is complete
- [ ] SharePoint setup is complete
- [ ] Video recording is complete
- [ ] Hackathon submission is complete

## Evidence

- [ ] Final backup video is rendered
- [ ] Live Agent citation shot is captured
- [ ] Microsoft IQ evidence is captured
- [ ] Final repository state is tagged or otherwise ready for handoff
